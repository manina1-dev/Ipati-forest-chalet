# Ipati Forest Chalet

Στατικό site για το Ipati Forest Chalet στην Υπάτη (ελληνικά / English).

## Πώς αλλάζω τα στοιχεία
Όλα τα βασικά (σύνδεσμος Airbnb, τηλέφωνο, email, Instagram, φωτογραφίες) είναι στο `js/config.js`.
Οι φωτογραφίες μπαίνουν στον φάκελο `images/`.

## Δημοσίευση (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → διαλέξτε το branch και `/ (root)`.
